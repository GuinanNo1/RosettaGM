MoveGM General MIDI for the Ableton Move

A General MIDI sound pack for the Ableton Move, and a converter that turns MIDI files into Move Sets that use it. Part of RosettaGM, which uses General MIDI as a common language between grooveboxes.

For testing. Everything here opens and plays in Ableton Live 12, but hasn't yet been tried on Move hardware. Keep backups of your Move Sets.

General MIDI pack

MoveGM v0.2

Sound pack for Move Manager

All 128 General MIDI instruments as Move presets, 12 drum kits laid out for General MIDI drum parts, and 23 Drift synths as alternatives for the synth sounds. Built from GeneralUser GS.

Converter

MIDI2Move alpha 0.7

MIDI file → Move Set

Turns a General MIDI file into a Move Set (.ablbundle) using the MoveGM sounds: drums on the kit, up to four instrument tracks, extra lines played on spare drum pads, and long songs split into scenes. Preview it in the browser first.
