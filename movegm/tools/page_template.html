How the samples were made

One sample per preset. Move's Melodic Sampler takes a single sample, so each program is recorded at one key (C1, C2, C3, C4 or C5 depending on its range). Voice Transpose brings it back to concert pitch.

Loops unrolled. Move has no sample loop mode, so the SoundFont loop is repeated into an 8-second sample with a fade at the end. Loop points are also written into each WAV.

Filter sweeps baked in. GeneralUser shapes tone with modulation envelopes; these are rendered into the sample at velocity 100. Move's own filter is left fully open.

Format. 44.1 kHz, 16-bit, mono unless the SoundFont layers are panned. Levels keep GeneralUser's balance through each preset's Volume.
