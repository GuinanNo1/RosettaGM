# Tool versions

RosettaGM started on 21 Nov 2026 from the CircuitGM repository, with its full history. The Circuit tools keep their own numbering. Paths below are relative to `circuitgm/`.

Each tool page shows its version next to its status badge, so you can tell which version a browser has loaded. GitHub Pages can take about 10 minutes to serve a new version; refresh with Shift-reload if a page shows an older one.

**Rule for every change to a tool:** bump its version here and everywhere the page shows it (badge in `<tool>/index.html` and `help.html`, the "for testing" note under the heading, the landing page card, the README table and the tool's own README title), add a line below, and bump the page's cache tag (`?v=…`) on the files you changed. MIDI2Rhythm takes its badge from `VERSION` in `js/m2r/app.js` and lists its versions in `midi2rhythm/help.html`.

## PatchWorker
- **0.20** (25 Nov 2026): automation lane under the piano roll and drum grid, on the same steps: the recorded knob movements of the pattern shown (the selected drum's in the drum grid). A list chooses the lane: a synth's Macros 1-8 (labelled with what each controls in the patch it plays), Level, Pan, Reverb send and Delay send; MIDI 1/2's Knobs 1-8 and the same four; a drum's Pitch, Decay, Distortion, EQ, sends, Level and Pan. • marks lanes with values in the pattern. Bars show the recorded values (thin bars for a knob recording's micro positions), a dashed line where the last value holds (fainter from the pattern's start, as it loops). Drag to draw a value on each step passed (Shift: on sixths of a step), double-click a step to clear it. Edits are project edits, heard at once and kept by Save. While the song plays, the macro knobs turn with recorded macro movements (outlined), and go back to the project's positions when it stops. The roll is the pads' height plus the lane (on a short window, scroll the panel to reach it). Test: `tests/ui_auto.cjs <Apricots pack>`.
- **0.19** (24 Nov 2026): a project copy that really differs from the pack's patch (Out Of Space DL project 1, Blue Monday projects 2-4 and 27) is what the editor edits while that project plays it, as on the Circuit Tracks, so the preview and the song are the same synth. A "Project copy" label shows it; its edits are project edits (Save in the TRACKS panel keeps them; the pack's patch is unchanged), with their own undo. Save to pack slot (status line, or Patch ▸ Save to pack slot…) puts the copy in a pack slot (the project's own slot by default) and the project then plays it; Edit the pack's patch switches the editor to the slot's patch (the song still plays the copy). Revert project brings back the saved copy. Test: `tests/ui_copy.cjs <Blue Monday pack>`.
- **0.18.3** (24 Nov 2026): a project's macro knob positions are the project's, as on the Circuit Tracks (it saves them in its copy of each synth patch). A project copy that differs from the pack's patch only in knob positions (or Keyboard Octave, which only sets the preview octave) now plays the pack's patch (so editor edits are heard in the song) at the project's positions; before, it played the copy, so the editor's preview and the song were different synths (Apricots project 1, Synth 2). With the project playing the patch being edited, the macro knobs show and turn the project's positions (heard in the song and on the keyboard; a project edit that Save keeps; the pack's patch is unchanged). Choosing another patch for a synth brings that patch's own positions. Test: `tests/ui_macros.cjs <Apricots pack>`.
- **0.18.2** (24 Nov 2026): micro steps numbered 1-6 (1 = on the step), on the pads, in the drum grid's box and in the status text. Micro Step view lights all six pads dimly and the ones played brightly (synth: chosen notes bright, other notes' micro steps in between).

Drum grid: sample flips are pink without the sample number (click a hit to hear it, hover for its name).
- **0.18** (24 Nov 2026): micro steps (User Guide pp. 48-51, 66). Setting a gate now keeps the tie (it used to clear it). Piano roll: Shift-drag moves a note in sixths (its micro step); a plain drag keeps it; moving keeps the tie.
